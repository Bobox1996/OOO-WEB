# Out Of Office Design website

This repository contains the Out Of Office Design portfolio. Its Git remote is `Bobox1996/OOO-WEB`, Vercel hosts the Next.js app, and Supabase stores project data and media.

## Handoff to GitHub Desktop

For website edits requested on `main`, verify the change and create a local commit containing the files or hunks for that task. Review the staged diff and preserve unrelated work, including any changes the user already staged. If verification is blocked, report the blocker and which checks passed. If the user requests a review or an uncommitted change, follow that request.

Give the user the commit ID. They publish by clicking **Push origin** in GitHub Desktop. Push or deploy on their behalf only when they ask.
