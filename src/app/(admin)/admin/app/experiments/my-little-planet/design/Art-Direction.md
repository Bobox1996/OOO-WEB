## 一座可以转动的海岸微缩模型

先读到星球轮廓，再读到海岸的层次，最后才看见草梢、沙粒和家具接缝。暖光落在沙岸上，水底从薄荷绿过渡到蓝绿色。

### 镜头的优先级

全景看球体和海湾；中景看谁在给谁投影；近景看主材质。布置模式保持清晰。摄影模式以后才可引入轻景深，焦点落在所选物体脚下。

## 先锁定日光，再评审颜色

色板是输入材质的 sRGB 起点。地形随深度、坡面和日照变化；道具在同一个灯光台上复核，设计稿用接触阴影传达重量。

| 材料 | 基础色 / 粗糙度起点 | 轮廓与表面 |
| --- | --- | --- |
| 干沙／湿沙 | #E3C992 / 0.90；#BDAA82 / 0.62–0.78 | 干沙细颗粒，湿沙更暗更平。当前地面共用近似粗糙度。 |
| 草／岩石 | #738348、#97A45F / 0.85–0.95；#9A9271 / 0.78–0.92 | 树冠保留暗部；岩石上面宽、下沿入土，层理跟随主方向。 |
| 织物／木材 | #899676 / 0.84；#A67E51 / 0.61 | 织物有宽软高光；木边在转折处接一条短窄高光。 |
| 浅水／深水 | #83C2AE、#337F83 / 0.30–0.38 | 浅处露底色，近岸断续泛白；深水高光细碎、稀疏。 |

网页基准使用 ACES Filmic、曝光 1.03、sRGB 输出。主灯来自左前上方，方向向量（−22, 35, 30），暖色 #FFE3B7，强度 2.03；半球补光 1.38，冷侧补光 0.72。资产灯台用面积光和 AgX，以网页中的材质并排效果作为最终判断。

## 不同轮廓，共享同一种手感

树冠、石头和草都从大形开始。改变物种时，先改变树干走势、宽高比和散布方式；相邻模板即使统一上灰色，也应能区分。

### 树｜剪影优先

海岸柏是低而饱满的聚伞，白桦有两条浅色主干和高冠，风剪松的枝盘向一边伸展。用成团叶簇打破外缘，在枝叉处留出天空透过的负形。

### 石与草｜在接触处交代材质

花岗岩分主次块，层理岩有一至两道较浅的水平断层，溪卵石成组降低重心。草叶从一簇根部向外张开，暗根亮梢。花瓣和种穗只出现在少数模板。

### 水与沙｜在岸线上交代厚度

剖面从草台、断续裸土、干沙、暗湿沙到透底浅水。水纹顺着溪轴或海岸延伸；控制浪线长度和亮度，让水面保留大片安静区域。

## 从一张参考图到可摆放模型

一次委托交付一个可反复检查的资产包。参考图约束款式，项目中的尺度、倒角、材质和灯光约束它如何出现在这颗星球上。

| 环节 | 交付和判断依据 |
| --- | --- |
| 01 读图 | 提供正面或 3/4 图、已知一条尺寸、预期占地和使用地表。列出必保轮廓、材质分界、结构特征。单图看不见的背面写明推定。 |
| 02 灰模 | 在 Blender 对照文件里用米建模。先拼主体积、腿与支撑；并排放一块溪石和一株草，在 64 px 缩略图、正常布置距离和近景检查 silhouette。 |
| 03 几何 | 木边倒角 4–15 mm，软垫转角 35–75 mm，织物包边 3–6 mm。调整法线与受光，不规则细节集中在有触感、能投影的位置。 |
| 04 材质 | 优先共用项目色板。非金属 metallic=0；主材通常 2–3 种。复杂织纹、木纹或苔点烘焙到贴图，Base Color 使用 sRGB，roughness、normal 与 AO 使用数据色空间。 |
| 05 导出 | 应用缩放，底部占地中心为原点，Blender +Z 向上、−Y 朝前；导出 GLB 后 +Y 向上、+Z 朝前。核对实测包围盒、三角面、材质、朝向和纹理路径。 |
| 06 入库 | 写入 id、revision、尺寸、占格、允许地表与支撑容差。网页加载后以相同灯光截取场景样张，检查四脚、90° 旋转和占格冲突；记录是否通过。 |

家具建议控制在 2k–8k 三角面，单件常用至多 3 个材质。简单石头 100–1,200 面、草簇 100–900 面可作新模型的起点；树冠视重复数单独评估。远景用实例化或减面，保留外轮廓。

## 双人沙发，怎样才算同一套道具

样件采用鼠尾草色双座垫、外露橡木扶手和四条短腿。正面小图仍能看见两块坐垫，侧面能辨出靠背后倾和扶手的水平线。

| 检查项 | 本例 |
| --- | --- |
| 体量和支撑 | 实测宽 1.600 m，深 0.760 m，高 0.789 m；底部在 Y=0。规划占格 2 × 1；座高约 0.47 m。 |
| 款式特征 | 两块靠垫、窄木扶手、可见的前横档；布垫的圆角明显大于木架。底部有真实透空。 |
| 资源与端侧复核 | GLB 实测 6,716 个三角面、3 个材质。导入网页后从正面、侧面、3/4 角度检查，陪衬物用同一组草和岩石。 |

## 在网页里作最后一次并排检查

同一件道具应能在整星、布置和微距三种观看距离下各贡献一种信息。模型通过 Blender 检查后，再进实际网页确认一次。

| 场景 | 通过条件 | 偏离时优先改哪里 |
| --- | --- | --- |
| 整星与缩略图 | 64 px 图能分清类别，三种树冠的轮廓可辨。海岸与海面颜色有明显明度差。 | 放大轮廓转折，合并碎件，减小细节对比。 |
| 草台近景 | 四脚落地；刚性模型不随球面弯折。木、布、石形成立即可读的高光差异。 | 修原点和支撑，再校正粗糙度与边缘半径。 |
| 溪岸与沙岸 | 水线贴合地面，石头入土，草根有遮蔽。草地与沙地交界有不规则过渡。 | 先改岸线轮廓和水深，再改泡沫。 |
| 桌面与手机 | 窗宽 390 px 时能单手选款；缩放后地形边缘可点、目录可读。无 WebGPU 时以 WebGL 2 检查相同模型。 | 先降像素比、远处植被和阴影，再缩减水面细节。 |

### 版本与交接

资产 id 保持稳定；改变实际尺寸、占格或支点时提升 revision 并复核旧摆放。建模包内的九个环境标本用于并排比较，沙发只作家具尺度样件。所有参数是本项目起始值；替换后需更新手册和资产描述。

## 站在水边，能看清什么

在角色尺度下，先检查水底轮廓与树冠透空，再检查草纹、石面和风。用相同的路线、相机距离和光照复测下一批模型。

### 水体分三层

河床提供沙粒、卵石与游动的焦散。水面以两组交错法线做轻微折射，按水深和视角衰减河床颜色。远侧的低角度反光可变亮，近岸仍要辨认石头边缘。泡沫只在细碎水线上出现。

### 风的分配

树、草和微波共用风向。树干脚与草根的位移归零，枝端和草尖受缓慢阵风，另叠少量短周期颤动。Blender 新资产沿根至梢绘制风权重，保持石头、座椅和树根稳定。

### 近景检查

以约 1.45 m 的角色为尺。近树替换为分枝叶片，通过叶隙能看到天空。近草增添细叶、花和种穗，岩面保留材质颗粒与层理。以脚边、隔溪对岸和全星缩略图三张同机位实机图验收。
