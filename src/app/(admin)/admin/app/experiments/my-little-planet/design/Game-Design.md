# My Little Planet · 游戏大纲 v0.3

[建模包：Blender 对照场景、沙发 GLB、资产描述与三张对照图](./Coastal-Modeling-Kit.zip)

## 把一段海岸放进一颗星球

玩家先在整颗星球上发现一条小溪，再靠近岸边，种下一株树。拉远时，这一笔改动仍能在星球的轮廓上找到。

### 第一轮试玩

选择「地形块」并开始编辑，用草地、沙地和水做出自己的岸线。也可以在「环境标本」放置树、草和岩石。进入步行探索，从岸边检查水深、坡度和植物尺度。

### 本轮交付

可逐块增删的海岸星球、三条溪流、十五种环境模板、单层剖切、撤销、浏览器存档和第三人称步行。多格家具与建筑保留在下一阶段。

## 一颗球，六个连续的网格面

六个等角投影面共同覆盖球面，2,400 根径向网格柱可各自堆叠半高模块。表面渲染与人物脚底都读取同一份模块数据。

| 参数 | v0.3 约定 |
| --- | --- |
| 海平面半径 | 14.00 m。1 个 Three.js 单位对应 1 m。 |
| 逻辑格 | 每面 20 × 20 格。用面中心的中轴弧长定义标称 x = π × 14 / 40 ≈ 1.10 m。各格的实际边长随球面位置略变。 |
| 厚度与层号 | 模块沿半径方向厚 x/2 ≈ 0.55 m。当前可编辑第 −7 至 +8 层。第 −1 层顶面为海平面，第 0 层顶面高出海面半格。 |
| 存储 | face、i、j、layer 唯一定位草地、沙地、水或空格。连续水面与缓坡都由邻块的真实占用关系生成。 |

### 接缝与地貌生成

相邻格共用实际的球面边和角点。相差一层的地块在边上共享中间高程，向两侧格心平滑回到本层标高。相差两层或更多时保留独立的顶面和外露崖面，台坎可用单块编辑改变。

## 先找支撑，再确认占地

自然标本沿当地地面朝向落下。刚性家具保持一个整体朝向，跨格验证所有支点；球面曲率由支撑容差或基座消化。

| 对象 | 行为与反馈 |
| --- | --- |
| 树、草、岩石 · 已实现 | 点击会吸附至格心。树和草需要干地；石头可放在露出的沙岸。用户已摆放的标本占格，重叠时显示原因。 |
| 沙地、小溪 | 沙地标本改变所在表面的颗粒和纹理。水道模板沿连续相邻格生成水块。手动编辑的模块覆盖水道模板。 |
| 家具 · 后续 | 预览从格中心或格间中点起算。偶数宽度对齐两格中线；绕合成法线以 90° 旋转。先算旋转后占格，再查实际支点、水面、碰撞与净空。 |
| 地形块 · 已实现 | 表面模式在最上方增加、挖去或换材。指定层号可编辑地下、悬空或邻格，剖层预览临时隐藏上方模块。每次操作只影响选中的一个模块。 |

跨面时沿球面投影每个支点并重新求格号。跨三面交点、支点落到不同台层、或家具四脚到支撑平面的最大误差超过 4 cm 时，显示冲突并保留预览。较大建筑先铺平整基座。

## 十五种模板，共用一套尺度

先改变轮廓和生境，再在有限范围内改变大小、转向和颜色。每颗星球都保留空地，植物在溪岸、坡肩和林缘形成可辨认的群落。

| 类型 | 模板 | 布置节奏 |
| --- | --- | --- |
| 树木 | 海岸柏／白桦／风剪松 | 坡肩疏植；树冠高低错开，保留开敞草台。 |
| 石头 | 花岗岩／层理岩／溪卵石 | 主石搭配伴石；水边选磨圆轮廓。 |
| 草地 | 针叶草丛／白花草甸／金穗草 | 草丛成片，白花集中，溪岸优先金穗。 |
| 沙地 | 细沙／贝屑沙／风纹沙 | 从湿沙到干沙渐变；三种材质使用同一沙色系。 |
| 小溪 | 缓弯／双曲／宽浅滩 | 三条独立水道预置不同形态。替换水道时同时更新河床、岸线与植被。 |

同款的初始自然分布采用确定性大小与偏转；玩家手动放置的模板用目录标准尺度。天然连续地貌可以跨面，用户操作记录在逻辑格或河道编号中。

### 存档与性能

存档 schema 2 记录标本、三条溪流形态及逐格覆盖项。空格覆盖可永久记录一次挖掘，恢复到生成状态会移除多余覆盖。schema 1 的标本和溪流选择在原浏览器自动读取，下一次编辑时写入新版存档。

## 从溪边登陆，绕着星球走

第一次步行从有卵石和低草的溪岸开始。人物脚下的方向始终指向球心，转弯时镜头跟随当地地面的朝向。

### 操作与落点

从「步行探索」出发，用 WASD 或方向键移动，按住 Shift 小跑，拖动画面环顾。触屏用左侧摇杆移动、右侧拖动环顾。「选择落点」返回全星，再点干地进入。Esc 或「返回全星」回到原来的环绕视角。

### 地面约束

角色先比较相邻可站立模块的整层差，再取缓坡表面高度。高差绝对值小于 x 可以双向通行，达到 x 就被地形挡住。单层浅水减速，两层水深需要绕行。树干和头顶净空单独检查。

### 验收线路

在溪边站定，观察叶梢与水纹。沿岸走几步，转镜看清卵石与草根，再从全星切换到另一侧的干地。编辑沙地或植物后可再次步行近看。

## 挖掉中间一块，上方仍然存在

每次操作以一个面、一个平面格和一个层号为单位。这样既能堆一阶海岸，也能挖出有顶的洞或摆出悬空水块。

### 增加、挖去与换材

增加要求目标格为空。挖去把目标格变为空格，换材只替换已存在的模块。自动模式作用于最上层。选定层号后，可以从球面任意方向编辑被遮蔽的一层。

### 水与空气

海由可编辑的水块叠成。相接水块隐藏内部面，共同绘制透明水面。挖走水块会留下空位，水体不会自动回填。恢复那个水块即可接回水面。

### 一层坡、两层崖

高度差等于 x/2 时，共享边的高度取两格顶面中值，坡面在格心前回到水平。相差至少两层保留外露立面。走路使用地层原始差值，因此从上方下崖也会被拦住。
