## 把一段海岸放进一颗星球

玩家先在整颗星球上发现一条小溪，再靠近岸边，种下一株树。拉远时，这一笔改动仍能在星球的轮廓上找到。

### 第一轮试玩

拖动环绕星球，选择标本并点击合适的地块布置。切到「步行探索」，沿溪岸检查改动，再返回全星。使用撤销可恢复上一步，同一浏览器刷新后能继续布置。

### 本轮交付

海岸星球、三级草台、浅海、三条溪流、十五种环境模板和第三人称步行。玩家可摆放自然标本、铺沙及替换现有水道。多格家具、建筑和主动升降地形列入后续阶段。

## 一颗球，六个连续的网格面

底图用立方球组织逻辑格，再用更密的三角网格绘制海岸。玩家可以绕过背面和两极，近看时仍能找到稳定的摆放位置。

| 参数 | 首版约定 |
| --- | --- |
| 海平面半径 | 14.00 m。1 个 Three.js 单位对应 1 m。 |
| 逻辑格 | 每面 20 × 20 格，共 2,400 格。按球面平均面积折算边长约 1.01 m；各格实长随位置变化。 |
| 地层 | 浅海床 → 湿沙 → 干沙 → 草台。干沙参考高程 +0.32 m，再按 0.48 m 跃升三层；坡缘连续过渡。 |
| 坐标 | 格号存为 face / i / j。立方体各面两轴按等角度采样，归一化得到球面方向。地面点为 n ×（14 m + 高程）。 |

### 接缝与地貌生成

邻接面共享边界方向，噪声取样使用三维球面方向。边界顶点位置一致，显示网格和拾取都回算到同一面、行、列。岛群采用固定种子分布，河床切入坡面并接入低处海水。

## 先找支撑，再确认占地

自然标本沿当地地面朝向落下。刚性家具保持一个整体朝向，跨格验证所有支点；球面曲率由支撑容差或基座消化。

| 对象 | 行为与反馈 |
| --- | --- |
| 树、草、岩石 · 已实现 | 点击会吸附至格心。树和草需要干地；石头可放在露出的沙岸。用户已摆放的标本占格，重叠时显示原因。 |
| 沙地、小溪 · 已实现 | 沙地刷覆盖约一至两格宽的低地，中心格记录材质。溪流替换仅在已有河道附近生效；新水道会淹没用户标本时拒绝变更。 |
| 家具 · 后续 | 预览从格中心或格间中点起算。偶数宽度对齐两格中线；绕合成法线以 90° 旋转。先算旋转后占格，再查实际支点、水面、碰撞与净空。 |
| 台地升降 · 后续 | 每次修改一档 0.48 m；邻格高度差最多一档。一次笔刷操作作为一个事务检查全部占格和水道，超限或已有支撑物时指出冲突格。 |

跨面时沿球面投影每个支点并重新求格号。跨三面交点、支点落到不同台层、或家具四脚到支撑平面的最大误差超过 4 cm 时，显示冲突并保留预览。较大建筑先铺平整基座。

## 十五种模板，共用一套尺度

先改变轮廓和生境，再在有限范围内改变大小、转向和颜色。每颗星球都保留空地，植物在溪岸、坡肩和林缘形成可辨认的群落。

| 类型 | 模板 | 布置节奏 |
| --- | --- | --- |
| 树木 | 海岸柏／白桦／风剪松 | 坡肩疏植；树冠高低错开，保留开敞草台。 |
| 石头 | 花岗岩／层理岩／溪卵石 | 主石搭配伴石；水边选磨圆轮廓。 |
| 草地 | 针叶草丛／白花草甸／金穗草 | 草丛成片，白花集中，溪岸优先金穗。 |
| 沙地 | 细沙／贝屑沙／风纹沙 | 从湿沙到干沙渐变；三种材质使用同一沙色系。 |
| 小溪 | 缓弯／双曲／宽浅滩 | 三条独立水道预置不同形态。替换水道时同时更新河床、岸线与植被。 |

同款的初始自然分布采用确定性大小与偏转；玩家手动放置的模板用目录标准尺度。天然连续地貌可以跨面，用户操作记录在逻辑格或河道编号中。

### 存档与性能

当前 schema 1 存储用户放置项、格号、款式、角度和三条溪流的形态。固定底图从代码重建。换底图前增加 generatorVersion 并做旧存档迁移；仪表盘不上传个人试玩布置。目标设备以实际测试为准：桌面 1080p 目标 60 fps，移动端 30 fps。先压缩像素比和远景植被，再缩减水面细节。

## 从溪边登陆，绕着星球走

第一次步行从有卵石和低草的溪岸开始。人物脚下的方向始终指向球心，转弯时镜头跟随当地地面的朝向。

### 操作与落点

从「步行探索」出发，用 WASD 或方向键移动，按住 Shift 小跑，拖动画面环顾。触屏用左侧摇杆移动、右侧拖动环顾。「选择落点」返回全星，再点干地进入。Esc 或「返回全星」回到原来的环绕视角。

### 地面约束

使用同一份地形高度计算脚底和溪底。浅水中减速，深于 0.31 m 的水域与树干阻止继续前进。人物可上缓坡，坡度与步高超过限制时停下。相机移动到人物与岩坡之间时缩短后退距离。

### 验收线路

在溪边站定，观察叶梢与水纹。沿岸走几步，转镜看清卵石与草根，再从全星切换到另一侧的干地。编辑沙地或植物后可再次步行近看。
