# Out Of Office experiment

Start with README.md and experiment.json. Build the app in page.tsx using React, TypeScript, relative imports and scoped CSS. The same page runs locally and inside the OOO admin.

Use the local preview to test changes and run npm run build before publishing. Update experiment.json when the name, author, release version or description changes. Confirm data contracts against OOO's own documented API and use local fixtures while contracts are being designed. Keep private credentials and server-only code out of client components.

Publish the experiment source in its own directory in Bobox1996/OOO-WEB as described in the README.
